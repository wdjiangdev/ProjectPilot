# Change log / 更新记录 / Änderungsprotokoll

## English

- 2026-11-25: OEM page: the template milestones in the Gantt chart are now optional, like the phase bands — the legend's Milestone entry is a checkbox (on by default); unticking it hides the whole milestone row (diamonds, labels and dates) and collapses its height, and the choice is saved with the project, kept in JSON export/import, and honoured in the PDF/JPG export legend.
- 2026-11-20: New Agile page (Agile ↗ in the main header): Jira-style backlog with epics/stories/tasks/bugs, story points and priorities; sprint planning on working days (Chinese holidays respected) with capacity; Kanban board with drag-and-drop and WIP limits; burndown and velocity charts; JSON and Jira CSV import/export. Epics can be linked to a Gantt task and push their progress (done points ÷ total) back as % complete. Data is stored separately from the Gantt and OEM pages.
- 2026-11-20: Agile fixes and additions: the burndown chart's last date label is no longer clipped, and the header and next-milestone banner no longer overflow on narrower windows; board cards now have ‹ › buttons to move issues between columns (works on touch screens), completing a sprint now asks in a dialog where to move open issues instead of a prompt, and the toolbar can filter the backlog by sprint. The burndown and velocity legends now sit in a strip above their charts instead of inside the plot area.
- 2026-11-20: Ribbon alignment: the search box text is now vertically centered (standard 13px font, line height matched to the box), and the completion % buttons (0/25/50/75/100) are centered — the little bars no longer squash and the numbers sit in the middle of their cells.
- 2026-11-19: Mobile, OEM page: same treatment as the main page — the header theme/language segmented controls now fit inside their containers on small screens, and the two tabs (Input Data / View Gantt) no longer float above their track; the Gantt tab re-renders at full width when switching.
- 2026-11-19: Mobile: the main page now shows the task table and the Gantt chart one at a time with two tabs to switch between, full width; the ribbon starts collapsed and its tabs scroll horizontally; tapping a selected task shows an "Edit task" button that opens the edit dialog. Also fixed: the header theme/language buttons overflowing their segmented controls on mobile, and in the Fit view the chart only filling ~270px after switching tabs with all narrow bar labels clipped — the timeline now fills the full width and task names are shown beside narrow bars.
- 2026-11-18: The user chip at the top right is now draggable: hold it to move it anywhere, and its position is remembered across reloads and pages.
- 2026-11-17: README restructured: all three language sections now follow the same Disclaimer, Overview, Features and Changelog structure.
- 2026-11-17: Added a login gate: the site requires login to access, registration needs an invite code, and a login stays valid for 30 days; admins can generate invite codes on the page.
- 2026-11-17: Supplier node date rows now show the name first and the date second, matching the customer milestone order.
- 2026-11-04: "Insert customer milestone" can now add custom customer nodes (name + date), inserted at the right position by date, automatically re-sorted when the date changes, and deletable.
- 2026-10-27: When the browser is zoomed (125%–200%), the ribbon no longer wraps into multiple rows and squeezes the table; it scrolls horizontally instead (mouse wheel works), and dropdown menus open normally.
- 2026-10-26: 2027 statutory holidays tentatively added to the Chinese calendar; the MPP conversion service address can be entered under "File → Import → More".
- 2026-10-16: Excel import/export upgraded: new Excel import (multiple worksheets, headerless name columns, outline levels, period columns), export switched to .xlsx with conditional-format Gantt blocks updating with dates and linked duration formulas; duration column shown by default (days/weeks/months).
- 2026-10-16: Vector PDF export, 600 DPI strips, automatic task-name wrapping; Chinese calendar with built-in 2023–2026 holidays and make-up workdays; Tesla customer milestones added; legacy ribbon removed.
- 2026-10-15: Default template changed to the 5 APQP phases with template names following the UI language, ribbon reorganized; OEM-Gantt supplier milestone rows auto-sort by date, diamonds draggable to change dates, labels never truncated, plus undo/redo, BMW milestones unchecked by default and recommended tasks collapsed by default.
- 2026-10-14: First release: MS Project-style scheduling (tasks, outline/WBS, dependencies, constraints, milestones, manual/auto scheduling), ribbon UI, trilingual UI, light/dark themes; Gantt chart, calendar view, network diagram, timeline, resources & cost, baselines, earned value tracking, critical path; customer milestones (OEM) with a standalone OEM-Gantt page, import of XML/MPP/GanttProject/JSON, export of PDF/Excel and more, undo/redo, keyboard shortcuts, Chinese and custom calendars, offline single-file build.
